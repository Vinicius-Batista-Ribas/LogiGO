# 🚚 LogiGo – Plataforma de Entregas

Este projeto é um sistema backend de entregas desenvolvido em Go, criado com o objetivo de estudar e aplicar conceitos reais de backend utilizados no mercado.

## 🎯 Objetivo

O objetivo deste projeto é evoluir progressivamente um sistema de entregas, começando por uma API simples e avançando para uma arquitetura baseada em microsserviços, cache, mensageria, CI/CD, deploy em nuvem e monitoramento.

## 🚧 Estado Atual do Projeto

Atualmente, o projeto está na **Fase 1**, focado em persistência de dados e organização da API.

Funcionalidades já implementadas:
- API REST básica
- Criação e listagem de pedidos
- Estrutura inicial do projeto

## 🛣️ Roadmap

O desenvolvimento do projeto segue as seguintes etapas:

- [x] Fase 0 – API básica em Go
- [ ] Fase 1 – Persistência com PostgreSQL
- [ ] Fase 2 – Organização em camadas
- [ ] Fase 3 – Cache com Redis
- [ ] Fase 4 – Mensageria
- [ ] Fase 5 – Microsserviços
- [ ] Fase 6 – Docker
- [ ] Fase 7 – CI/CD
- [ ] Fase 8 – Deploy em nuvem
- [ ] Fase 9 – Monitoramento
